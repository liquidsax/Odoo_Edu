> 2026-09-29 交付，2026-10-03 起改名 R3ynA 学习平台。基于 Odoo 19 社区版（业务库 `OdooForDB`），自定义模块 `tutoring_center`。

## 二、教师端日常操作（后台 → 顶部菜单"R3ynA 学习"）

菜单：**学生 / 错题 / 练习册 / 知识点 / 错因**。

1. **学生**：建学生档案（保存时自动创建关联联系人）。点表单上方"门户账号"按钮打开联系人 → 在联系人表单点"授权门户访问"即可给学生/家长开通登录账号。
2. **教学内容**：即输即建的内容标签（如"一元一次方程"）。不预置目录，按你的教学进度随时添加。
3. **知识点**（顶部菜单"知识点"）：可按年级维护，也能用「上级」列把条目挂成树（年级 → 专题 → 知识点），列表里的「完整路径」列读作"高中 / 集合、常用逻辑用语与不等式 / 不等式的解法"。模块**自带一套高中知识点**（11 个专题、87 个考点，来自《53A 数学精讲册》目录），新装的库开箱就有；你在这套数据上的改名/归档不会被系统升级还原。学生档案"知识点掌握"页签挑知识点时，高一/高二/高三能看到整个高中库，初中只看本年级——**错题上挑知识点用的是同一套年级范围**。
4. **错因**（顶部菜单"错因"）：录错题时下拉里就是这一套，按"概念 / 审题 / 运算 / 策略 / 习惯 / 其它"六类预置 13 条。拖手柄能调顺序，觉得不合用可以改或加——预置数据是 `noupdate=1`，你的改动不会被升级还原。
5. **辅导课次**：每次上课记录日期、时长、讲授内容（打标签）、课堂表现、下步计划。
6. **考试成绩**：考试名称/类型/日期，得分明细**按教学内容拆分**（如"一元一次方程 44/50"），得分率自动汇总。
7. 分析视图：错题、考试成绩列表右上角可切**图表**看趋势；学生档案内嵌该生全部记录标签页。

## 三、学生/家长端（门户）

登录后自动进入 **/my/learning 我的学习**；顶栏三个入口：**学习平台 / 错题 / 函数图像**。

- **我的学习**：统计卡（考试平均得分率、已上课次等）、成绩趋势图、最近课次与考试。
- **错题**（`/my/mistakes`）：
  - 上方**速记条**记出处（练习册 + 页码 + 题号，题号可写 `1-5`、`1,3,7` 自动拆多条）；「更多选项」里挑**错因**与**知识点**——知识点只给这个学生年级能用的那些。
  - 下面是**卡片**：正面只有知识点（没标就退回显示教学内容）、难度辣椒、错因、出处和一句补充说明。
  - 工具条可以**搜索**（题号/页码/知识点/错因/说明/书名）、切**筛选药丸**（本月 / 高难度 / 未标错因 / 未选知识点，都带计数）、切**分组**（按知识点 / 按错因 / 按月份）、调**每页条数**（10/20/50）。
  - 点分组标题会**下钻**到那一类的全部错题，条件以胶囊形式挂在列表上方，× 可单独摘掉。
  - 点卡片进详情：看教材里出错的那一页，下方**直接补一句想法**就能保存，不必跳去整张编辑表。
  - **列表默认顺序就是"该看的先看到"**：每打开一道题，系统自己记一次并把这道题往后推（1→3→7→15→30→60 天）。这套排期不在任何界面上出现，学生不需要知道它的存在，只要按着列表从上往下看。
- **教材**（`/my/learning/workbooks`）：只读阅读自己用过的练习册 PDF。
- 数据**按门户联系人硬隔离**，每个学生只能看到自己的（含家长共用学生账号的情况）。

## 四、数据与账号管理

- **改学生姓名/年级**：后台 → 学生 → 编辑。
- **删除示例数据**：示例学生B 及其账号（student02）在 学生/设置→用户 里删除即可；学生A 的课次/考试是演示数据，正式使用前可清掉重新录。
- **新建学生流程**：学生 → 填姓名/年级 → 保存 → 点"门户账号" → 联系人页"授权门户访问" → 填登录邮箱 → 邀请邮件（本机未配邮件服务器时，在 用户 表单直接设初始密码并口头告知对方）。
- **后台应用菜单**：左上角菜单已精简为 R3ynA 学习/联系人/网站/应用/设置（讨论、项目、邮件营销、调查、员工、仪表板 已隐藏）。如需临时恢复某个应用，到 设置 → 用户 → admin → 勾选"显示全部应用菜单"即可。

## 五、运维要点（继承自本机 README）

- 服务控制：`svcctl.ps1 status/check/start/stop/restart`，判断可用性用 `check` 不要只看服务状态。
- 自定义模块位置：`E:\Odoo\server\addons\tutoring_center`（`odoo.conf` 的 `addons_path` 已包含此目录）。
- 改模块代码后：`stop odoo` → CLI `-u tutoring_center --stop-after-init` → `start odoo`。
- 备份：`E:\Odoo\backup\` 内有改造前全量备份（2026-09-29）；日常备份 = pg_dump + filestore 两者都要。
- 卸载记录：本次共卸载 30 个无关模块（电商/营销/HR/客服/主题等），已装模块 74 → 44。
