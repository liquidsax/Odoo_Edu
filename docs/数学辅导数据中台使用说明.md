## 二、教师端日常操作（后台 → 顶部菜单"数学辅导"）

1. **学生**：建学生档案（保存时自动创建关联联系人）。点表单上方"门户账号"按钮打开联系人 → 在联系人表单点"授权门户访问"即可给学生/家长开通登录账号。
2. **教学内容**：即输即建的知识点/内容标签（如"一元一次方程"）。不预置目录，按你的教学进度随时添加。
3. **知识点**（顶部菜单"知识点"）：可按年级维护，也能用「上级」列把条目挂成树（年级 → 专题 → 知识点），列表里的「完整路径」列读作"高中 / 集合、常用逻辑用语与不等式 / 不等式的解法"。模块**自带一套高中知识点**（11 个专题、87 个考点，来自《53A 数学精讲册》目录），新装的库开箱就有；你在这套数据上的改名/归档不会被系统升级还原。学生档案"知识点掌握"页签挑知识点时，高一/高二/高三能看到整个高中库，初中只看本年级。
4. **辅导课次**：每次上课记录日期、时长、讲授内容（打标签）、课堂表现、下步计划。
5. **作业**：布置日期/截止日期/总题数/正确题数（正确率自动算），状态流转 已布置→已完成→已批改，可写教师反馈。
6. **考试成绩**：考试名称/类型/日期，得分明细**按教学内容拆分**（如"一元一次方程 44/50"），得分率自动汇总。
7. 分析视图：作业、考试成绩列表右上角可切**图表/透视表**看趋势；学生档案内嵌该生全部记录标签页。

## 三、学生/家长端（门户）

登录后自动进入 **/my/learning 我的学习**：

- 顶部统计卡：考试平均得分率、作业平均正确率、待完成作业、已上课次
- 成绩趋势图、作业正确率图（最近 10 次）
- 待完成作业提醒（黄色卡片）
- 最近课次 / 最近考试，及各自的完整列表页
- 全部只读；**每个学生只能看到自己的数据**（含家长共用学生账号的情况）

## 四、数据与账号管理

- **改学生姓名/年级**：后台 → 学生 → 编辑。
- **删除示例数据**：示例学生B 及其账号（student02）在 学生/设置→用户 里删除即可；学生A 的课次/作业/考试是演示数据，正式使用前可清掉重新录。
- **新建学生流程**：学生 → 填姓名/年级 → 保存 → 点"门户账号" → 联系人页"授权门户访问" → 填登录邮箱 → 邀请邮件（本机未配邮件服务器时，在 用户 表单直接设初始密码并口头告知对方）。
- **后台应用菜单**：左上角菜单已精简为 数学辅导/联系人/网站/应用/设置（讨论、项目、邮件营销、调查、员工、仪表板 已隐藏）。如需临时恢复某个应用，到 设置 → 用户 → admin → 勾选"显示全部应用菜单"即可。

## 五、运维要点（继承自本机 README）

- 服务控制：`svcctl.ps1 status/check/start/stop/restart`，判断可用性用 `check` 不要只看服务状态。
- 自定义模块位置：`E:\Odoo\server\addons\tutoring_center`（`odoo.conf` 的 `addons_path` 已包含此目录）。
- 改模块代码后：`stop odoo` → CLI `-u tutoring_center --stop-after-init` → `start odoo`。
- 备份：`E:\Odoo\backup\` 内有改造前全量备份（2026-09-29）；日常备份 = pg_dump + filestore 两者都要。
- 卸载记录：本次共卸载 30 个无关模块（电商/营销/HR/客服/主题等），已装模块 74 → 44。
