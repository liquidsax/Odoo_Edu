## 白天：网站新增「函数图像」绘图页

分支 `feature/website-function-plot`，提交 `53df6d5`（已 rebase 到 `e4d1fba` 后推送，PR 待开）。

### 交付内容

- 新公开页面 `/tools/function-plot`（`controllers/tools.py`，`auth='public'`），挂网站顶栏**第三位**（`website.menu` seq=30，位于 首页 / 学习平台 之后）。
- 主入口是**按类型填参数**：圆 / 椭圆 / 双曲线 / 抛物线 / 直线 / 二次函数 / 反比例 / 三角函数，点开弹层照题目填数即可；原手写方程框收进折叠的「自己输入方程（高级）」。
- 椭圆与双曲线各有两种填法：**分母式**（`x²/5+y²=1` 填 5 和 1）与**系数式**（照抄题目，`x²-4y²=4` 填 1、-4、4）。系数式是为避免教师为凑「右边为 1」心算而加（来自维护者的实际反馈）；参数不合法时预览处红字提示且不入图。
- `static/src/function_plot.js`（约 1600 行）+ `function_plot.css`，**零第三方依赖**（Chart.js 只能画统计图，画不出椭圆/双曲线）：
  - 解析：归一化（全角括号/等号、`²³`、`π`）→ 分词（连写字母拆分、隐式乘法）→ 调度场算法 → RPN → 闭包编译（不用 `eval`，避免 CSP 与注入问题）；
  - 判别与绘制：数值差分判断能否解出 y —— 能则显式采样、按跳变断开断点；不能（圆/椭圆/双曲线、`x²=±2py` 以外者）走隐式 marching squares，鞍点按中心值决定连接；
  - 两轴等比例（圆必须正圆）、1-2-5 自适应网格、滚轮以光标为锚点缩放、拖动平移、双击重置、悬停十字线读数——曲线画在主 canvas，十字线与读数画在叠加 canvas，避免每帧重算；
  - 全屏用 CSS 覆盖层（`100dvh` 兼容手机动态工具栏），同时尽力调用原生 Fullscreen API 并兜住 Promise 拒绝；
  - 弹层预览与曲线图例按数学写法渲染（`prettyEquation()`：`^n`→上标、`pi`→π、`log`→lg、去多余括号、`π·x`→`πx`），**先转义再替换**，注入的只有 `<sup>`。

### 本次抓到的三个真 bug（均已修）

1. **双曲线「焦点在 y 轴」两个分母用反**，与字段标签矛盾 → 会画出错误的双曲线（Node 用例发现）；
2. **正弦按周期换算时拼出 `pi/2x`**，被解析器读作 `pi/(2x)` → 图像错误；改为非纯数字一律补 `*`（`pi/2*x`）；
3. **画布内按钮点不动**：拖动处理对 `pointerdown` 调 `preventDefault()`，按规范会抑制浏览器合成的 `mousedown`/`mouseup`/`click`，导致「全屏查看」「重置视图」对真实鼠标点击毫无反应，`dblclick` 同被抑制（双击重置失效）。修法：命中 `button/a/input/label/弹层` 时直接放行；双击重置改为按 pointerdown 间隔（300ms）自行判定。

### 验证记录

- Node 用例 40+ 条：解析优先级（`2x^2`、`-x^2`、`2^-1`）、显式/隐式/竖直线判别、8 种类型的方程拼装与关键点代入、非法参数、渲染字符串、HTML 转义。
- 浏览器像素级实测：
  - `x^2/4+y^2/9=1` → 4.05 × 5.99 单位（真值 4×6）；`x^2+y^2=4` → 4.01 × 4.05（正圆，等比例成立）；
  - `x^2-4y^2=4` → 顶点精确落在 ±2，`|x|<1.9` 区间**零墨迹**（两支不连线，不会把渐近线当曲线画出来）；
  - `y=1/x` → 坐标轴两列零墨迹，两支断开；
  - 滚轮缩放 1.595×（理论 1.568）、拖动位移与指针一致、悬停读数正常；
  - 全屏：画布后备尺寸 454×487 → 531×785（= 视口 × dpr），退出后复原。

### 流程与工具结论（对后续开发很重要）

- **`static/src` 下的前端 JS/CSS 改动，刷新页面无效**，必须 `-u tutoring_center` 升级重建资产包（或启动加 `--dev=assets`）。已写入 `ONBOARDING.md` 热重载表与 handoff 第四节。
- 自动化验证的两个坑：
  1. Qoder 内置浏览器面板处于后台（`visibilityState=hidden`）时，**驱动点击不会向页面投递任何鼠标事件**，`requestAnimationFrame` 不触发、`setTimeout` 被节流到 ≥1s —— 此时"点击无效"之类的结论一律不成立；
  2. 脚本里用 `element.click()` 合成事件会绕过 `pointerdown → click` 链路，**掩盖上面第 3 个 bug**。交互控件必须真实点击验收。
- 用隐藏页里也能跑的方式验证：与重绘无关的探针（读 `defaultPrevented`、读视图状态换算出的读数、`getBoundingClientRect`）优先于"看像素/看截图"。
