## 一、根因：那两件事是同一个洞的两面

错题速记条那个下拉取的是 `tutoring.workbook.search([])`（`controllers/portal.py`），
门户「教材」页、错题「展示那一页」`_locate_page()`、AI 摘要定位，**认的全是 `tutoring.workbook`**。
而知识库上传只建一条 `tutoring.library.item`——那个「练习册 / 教辅」分类只是条目身上的一个标签，
**永远不会变成一本 `tutoring.workbook`**。真正把文件挂成"一本书里的一份教材"的是
`tutoring.workbook.file`（委托继承条目），而它过去唯一的入口是后台练习册表单里的「上传教材」
（`tutoring.workbook.action_new_file`）。

所以：①"建不出练习册"与②"传了却看不见"不是两个 bug，是**知识库这条路根本没接到练习册那套上**。
本机看不出来，只因为业务库那 3 本练习册是早先在后台建的。

## 五、新陷阱 59~60

**59. 委托继承建子记录时，如果显式给了父记录 id，核心会把 vals 里那些"继承字段"回写到父记录上**
——`odoo/orm/models.py:4699` 那段 `parent.write(data['inherited'][model_name])`。
后果很安静：`tutoring.workbook.file.create()` 里那句 `vals.setdefault('user_id', self.env.user.id)`
在超用户跑的迁移里会把**知识库条目的归属改成 superuser**，一个人的私有文件就这样判给了 1 号。
凡是"复用已有父记录"地建子行，继承字段（尤其 `user_id`）必须显式带上原值。
另一半：父记录已存在时**不会**再走父表的 `create`，所以想靠父模型 `create` 做默认值的地方要另想。

**60. `has_access()` 在 `env.su` 下恒为真**（`odoo/orm/models.py:4128`：`return self.env.su or not ...`）。
所以迁移里想问"这个人的账号本来能不能建练习册"，拿迁移那个超用户环境问会得到清一色 True，
等于替学生把私有条目升成了公共的一本——与运行时那条界线正好相反。
必须换成归属人自己的环境问：`env(user=uid, su=False)['x'].has_access('create')`，
或等价的 `Model.with_user(uid).has_access('create')`（`models.py:6001` 明确带 `su=False`，
只有目标本身就是 superuser 时才留在超用户模式）。

## 六、同晚第二条分支：函数图像页的参数滑块（`19.0.1.21.0`）

> 需求来自维护者本人，附了一张 Desmos 的截图（`y = 3x + b` 那行下面挂着「添加滑块：b」）：
> 「继续优化 `/tools/function-plot`，尽可能对标 Desmos，比如给函数或各种曲线添加滑块改变数值」。
>
> 拍板口径（四条都是选项式问出来的）：**两条路都通**（自己写的方程 + 那 8 个曲线类型的弹层）/
> **保持现有纵向布局**（不照 Desmos 改成左右双栏）/ **这轮只做滑块**（动画播放、`f(x)` 定义、
> 不等式着色、参数方程极坐标都不捎）/ **状态不存进 URL**。
> 按规矩只写代码 + 在一次性库上验，共享服务与 `OdooForDB` 一行没动。

### 根因：不是"没做滑块"，是引擎根本不认自由字母

`static/src/function_plot.js` 的解析器只白名单 `x`、`y`、`pi`、`e` 和函数名，
其余字母在 `pushName()` 里直接 `throw 未知符号`。所以 `y=3x+b` 敲进去是**报错**，
不是"能画但拖不动"。要上滑块得一起改通四件事：

1. 解析器把未知字母认成**参数**；
2. 编译出的闭包 `(x, y) => number` 要有地方取参数的值；
3. 那 8 个类型的 `compose()` 现在把数字**烤死在方程字符串里**（`x^2/4+y^2/9=1`），
   参数一旦会动，方程得改写字母，离心率/渐近线这些附带信息还得跟着实时重算；
4. 图例（`renderLegend`）如果显示烤数字的方程，拖一下滑块那一行字就跳，读不出"刚才动的是哪个旋钮"。

### 改了什么

- **解析层**（`function_plot.js` 一、二节）
  - `pushName(raw, tokens, followedByCall)`：拆不出已知符号的单个字母 → `{type:"param"}`；
    **参数名保留大小写**（弹层里的 `A`、`B`、`C` 与常数 `e` 是两个符号）。
    唯一的大小写例外是 `E`：小写 `e` 是自然常数，大写 `E` 必须能当参数，
    否则圆的一般式 `x²+y²+Dx+Ey+F=0` 里的 E 会被读成 2.718（见新陷阱 61）。
  - 一整串未知字母紧跟着括号（`sn(x)`）报"未知函数"，单个字母仍按隐式乘法放行（`a(x+1)`）。
  - `compileRPN(rpn, scope)`：参数在**编译时绑成常量**。滑块一动就整条曲线重建一次模型，
    闭包就不必带第三个参数——`solveForY()` 的线性判定、`strokeImplicit()` 的采样、
    悬停读数全部原地不动。重建的代价是解析+编译（微秒级），跟一次等值线扫描比可以忽略。
  - `buildModel(expression, params)` 多返回一个 `used`（这条方程用了哪几个字母），
    `evalConstant()` 拒绝参数（滑块数值框里不许引用别的滑块）。
- **拼式层**（`CURVE_TYPES`）
  - 字段声明 `sym`（方程里的字母）、`pow`（带指数：分母写 `a^2`）、`storesPower`
    （字段存的数就是这个幂，所以滑块带 `a=√分母`）、`range`（滑块默认区间）。
    只有椭圆/双曲线分母式的 `a2`/`b2` 与抛物线的 `twoP` 用到映射，其余一律恒等。
  - `compose(mode, v, sym)`：勾了滑块的字段在方程里写字母。`centered()`、`squaredTerm()`、
    `linearCombination()`、`conicCombination()` 各加一条字母分支——
    **字母自带正负号，所以不再做"省略系数 1 / 合并加减号"的美化**（`y=kx+b` 而不是 `y=2x-3` 那种）。
  - 数值校验照旧跑真数：`v.a2 <= 0` 这类判断在滑块拖进非法区间时仍然拦得住，
    拦下来的话只坏那一条曲线，其它照画。
- **参数注册表**（`PlotSurface`）
  - **参数是每条曲线自己的**：`curve.params = Map(字母 → {value, min, max, step, label})`。
    两条曲线各写各的 `a` 就是**两个互不相干的旋钮**（维护者第一轮验收时提的要求：
    "每一个函数都有自己可以改的参数，选中这个函数之后才会出现参数调整滑块"）。
  - `this.selected` 记当前选中的那条：**图例里方程那一行做成真按钮**（`button.tutoring_plot_legend_pick`），
    点一下（或 Tab 过去按回车）就选中，滑块条整条换成它的参数，标题写明「哪条方程」的参数；
    没选中的行挂一枚「N 个参数」徽标，不然参数藏在点一下之后看不见。
    选中那条在画布上**线宽 3**（其余 2），否则无参数的曲线选中后没有任何反馈。
  - 新加的曲线自动成为选中项；删掉选中的那条，选中回落到最后一条。
  - 滑块默认 `-10 ~ 10`、步进 `0.1`；字段声明了 `range` 的按字段来（几何量给 `0.1 ~ 10`）。
    数值框里填越界的数不夹回去，而是**撑开区间**。
  - `setParam()` → `refreshCurve(选中那条)` → 只重建这一条的模型 + 图例 + 数值框 + `scheduleDraw(coarse)`；
    拖动中走粗采样（`cell=12`），松手 `change` 再补一次细描。
- **UI**
  - 图例下面多一条 `data-plot-sliders`：字母 + 拖动条 + 数值框 + 齿轮（区间/步进，
    步进框收 `pi/4` 这种算式，讲三角函数时按 π 的分数走）。滑块条在 stage **外面**，
    不受画布那条 `pointerdown.preventDefault()` 影响（陷阱 8 的老坑）。
  - 弹层里每个能变滑块的字段下面多一个「滑块 a」勾选框（字母就是该字段声明的 `sym`）。
  - 图例那行显示**带字母的**方程（`x²/a²+y²/b²=1`），离心率/渐近线徽标实时重算。
- `website_templates.xml`：页面说明与底部帮助文字补了滑块那条；`function_plot.css` 补滑块条样式；
  manifest `19.0.1.20.0` → **`19.0.1.21.0`**（无迁移目录，纯前端）。

    ⚠️ 这两条是**第一版**（全局同名共用）的现场，同晚按维护者要求改成"参数归每条曲线私有 + 选中才出滑块"，
    改完的复验见下面「六之二」；
  - 双曲线勾 `滑块 a` 后把 `a` 填成 0 → 只有那条挂出「这个值画不出来 / 两个分母都要大于 0」，
    预置椭圆照画（实测仍有 1113 个自身颜色像素），填回 3 自动恢复；
  - 「清空图像」→ 滑块条整条收起；齿轮改步进为 `pi/4` 生效、把 `min` 改到当前值之上会把值夹回来；
  - 回归：不勾滑块的类型添加仍是数字式（`x²/4-y²/9=1` + 渐近线徽标）、三角函数弧度制照旧、
    console 无报错（只剩我自己 `getImageData` 的性能提示）。
- ⚠️ **截图仍欠**：走完真机点击之后面板 `visibilityState` 转成 `hidden`，
  `take_screenshot` 报 `NATIVE_BROWSER_VIEWPORT_UNAVAILABLE`（陷阱 29 同款现场）。
- ⚠️ 上面「共用字母 / 删除回收 / 非法值 / 齿轮 / 清空 / 回归」这六组是**用脚本派发真实 DOM 事件**跑的
  （`dispatchEvent(new Event("change"))`、`new MouseEvent("click")`），不是真人点的：
  点击与键盘那条链路已经在前面的真机步骤里验过，这几组要验的是状态机逻辑。
  接手的人要在浏览器里再过一遍眼睛，请自己点一次。

### 六之二、同晚改法：参数归每条曲线私有，选中哪条才摆哪条的滑块

维护者看完第一版的描述后提了一句："也就是说你的滑块，不是每个函数单独可选中去针对调？"
——确认他要的是**每条函数有自己的参数、选中才出滑块**，于是把"同名跨曲线共用"整套换掉：

- `PlotSurface.params` 这张全局表搬进 `curve.params`；`pruneParams()` 随之删除（参数随曲线生死）。
- 新增 `this.selected`；`rebuildCurve`/`setParam` 只认这条曲线自己的参数表，拖动时**只重建这一条**。
- 图例里方程那一行由 `<span>` 改成 `<button class="tutoring_plot_legend_pick">`：
  第一版只给行加了 click 监听，结果 a11y 树里那是一段 StaticText，**键盘根本选不中**
  （browser-use 也点不了：`this.scrollIntoView is not a function`）。做成真按钮才点得动、也才 Tab 得到。
- 未选中的行挂「N 个参数」徽标；选中那条画布上线宽 3。
- 弹层里"这个字母已被别的曲线用过"的提示随之去掉。

**复验**（同一个一次性库与 8899 进程）：

- 加 `y=a(x-h)²+k` 与 `y=ax²+m` 两条 → 各自长自己的滑块；把第一条的 `a` 填成 5，
  点第二条那行 → 摆出来的是 `a=1`、`m=1`（**两个 a 互不相干**）；点回第一条 → `a=5` 还在。
- 真机点图例那行（`button "y=a(x-h)2+k"`）→ 滑块条标题从「y=ax^2+m」的参数换成「y=a(x-h)^2+k」的参数 ✓。
- 删掉选中的那条 → 选中回落到最后一条，滑块条跟着换 ✓。
- 离线 101 项重跑仍全绿（解析层与拼式层没动，改的只是参数归属与 UI）。
- ⚠️ **像素断言一度把我带偏**：改完 `h` 之后量顶点，三次读数全是第 360 列，看着像"图不跟参数走"。
  真因是浏览器面板此时已 `visibilityState=hidden` → **`requestAnimationFrame` 不跑**，画布冻在最后一帧，
  而 DOM（数值框、图例、徽标）是同步更新的所以全对。派发一次同步重绘（点「重置视图」走 `drawMain()`）
  之后顶点立刻落到第 228 列 ＝ `h=-3` 在默认视图下的位置（`(−3+10)×32.9≈230`）✓。
  这条与陷阱 29、63 是同一族：**面板 hidden 时像素结论一律作废**，判据见新陷阱 65。

## 七、新陷阱 61~65（函数图像滑块这轮挖的）

**61. 字母连写会被贪心拆解器"吃掉"，方向是静默算错而不是报错。**
`KNOWN_NAMES` 按长度倒序贪心匹配，所以 `Asin(x)` 拆成 `asin` + `(x)` —— 振幅滑块 `A` 与 `sin`
连写就成了反三角函数。两处必须补 `*`：`compose()` 里振幅那一段写 `${sym.A}*sin(...)`；
以及 `prettyEquation()` 的"字母相邻省点号"美化规则（`π·x → πx`）要跳过两种情况——
后面紧跟函数名（`A·sin` 不能写成 `Asin`），以及点号左边是斜杠（`2π/T·x` 省成 `2π/Tx`
会被读成"分母里带着 x"）。另一半：参数名保留大小写之后，`e` 与 `E` 必须是两个符号
（圆的一般式 `x²+y²+Dx+Ey+F=0` 的 `E` 若被读成自然常数，那条曲线照样画得出来，只是是错的）。

**62. 滑块这种"参数会动"的模型，编译时把参数绑成常量 + 每次改动整条重建，比给闭包加第三个参数划算。**
`buildModel(expr, params)` 里参数直接编译成 `() => value`，`compileRPN` 之后所有闭包签名仍是
`(x, y) => number`，于是 `solveForY()` 的数值差分判线性、`strokeExplicit/strokeImplicit/strokeVertical`
的采样、悬停读数**一行都不用改**。反过来给闭包加 `p` 就躲不掉一件事：
`Ax+By=0` 的"能不能解出 y"本身是参数的函数（`B` 拖到 0 就不再对 y 线性），
带第三参数就得把这套判定也搬进每一帧拖动路径。一次解析+编译是微秒级，
而一次等值线扫描是 `(658/3)×(487/3) ≈ 3.5 万` 次求值，重建的开销在测量噪声里。

**63. 浏览器自动化：会重建 DOM 的控件，每次变动之后必须重新 snapshot，别复用旧 uid。**
这轮图例（`renderLegend`）与滑块条在每次参数变动时都重建节点，Playwright 风格的 uid 指向的是
**已脱离文档的旧节点**，下一次点击会落到坐标上现在的别的元素——现场表现为"我点了一下重置视图，
两格滑块的值被神秘改了、曲线跟着变"。这不是产品 bug（真人的点击永远打在活节点上），
是验收脚本的坑。判据：只要上一步动过 DOM（加/删曲线、拖滑块、开合弹层），就重新取一份快照再点。

**64. 起独立验收进程要带 `--limit-time-real`；改了 `static/src` 必须重启进程才会被读到——Odoo 19 的 `--dev` 根本没有 `assets` 这一档。**
默认 `limit_time_real=120` 打的是 werkzeug 请求线程的**虚拟实时**（连 `rfile.readline()` 等下一个
请求的时间也算进去），所以一个挂着十几分钟只在浏览器里点几下的进程会被自己判超时退出，
日志里只留一句 `virtual real time limit (159/120s) reached` 加一段 socket 栈。
另一半：`--dev` 在 19 里只认 `access qweb reload xml`（`odoo/tools/config.py:29` 的 `ALL_DEV_MODE`），
`--dev=assets` **不报错、也不生效**；资产包的版本是 registry 加载时算的
（`base/models/assetsbundle.py` 的 `bundle_version` → `get_version`），所以磁盘上改了 JS 而进程不重启，
浏览器拿到的还是 `ir.attachment` 里那一份——这轮就撞上一回：改完两分钟刷新页面，图例行仍是 `<span>`。
落地办法只有两个：**重启那个进程**，或者按陷阱 14 删掉 `web.assets_frontend.min.js/.css` 两条 attachment。

**65. 浏览器面板 `visibilityState=hidden` 时 `requestAnimationFrame` 不跑，画布冻在最后一帧——DOM 断言仍然有效，像素断言全部作废。**
这轮两次被它带偏：第一次以为"拖动滑块后隐式曲线停在粗采样"，第二次以为"改了 `h` 图完全不动"
（三次量顶点都在第 360 列）。实际都是 rAF 被挂起，`scheduleDraw` 排的那一帧根本没执行，
而同步更新的数值框、图例、徽标全都对，看上去就像"状态对了、渲染坏了"。
判据与绕法：① 断言像素前先读 `document.visibilityState`；② 要拿一次确定的重绘，
派发一个走**同步 `drawMain()`** 的动作（点「重置视图」、或触发 `resize()`），别依赖 rAF；
③ 反过来，`take_screenshot` 报 `NATIVE_BROWSER_VIEWPORT_UNAVAILABLE` 就是这个现场的信号。
与陷阱 29（面板 0×0 时指针动作被系统拒绝）、63（uid 指向已脱离节点）同族：**这个面板给的"没报错"不等于"验过了"**。
